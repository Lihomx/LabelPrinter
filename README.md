# LabelMaster Pro - 智能标签工作站 🖨️

专为跨境电商（美客多 Mercado Libre、亚马逊等）和海外仓打造的**高保真热敏打印与 PDF 智能拆分系统**。

---

## ✨ 核心亮点

- ✂️ **PDF 智能拆分助手（对标 Infotrekx）**：
  - 自动识别 A4 满版 30 贴、美客多 2 合 1 箱唛、上下双拼、单标智能裁切。
  - **自动过滤空白页/空白格**，绝不多浪费一张热敏纸。
  - **相同条码智能聚合折叠**，支持数量加减改数与平铺双重视图。
- 📋 **合规模板快捷制作（告别 Word 排版）**：
  - 内置西语商品合规信息表（100×100mm）、外箱箱唛标（100×100mm）、商品条码贴（70×30mm / 50×30mm）。
  - 支持 **Excel 批量导入**，一键生成成百上千张不同 SKU 标签。
  - 智能词组折行，彻底杜绝 Word 截断单词的排版问题。
- 🎨 **轻量可视化自由设计器（Web BarTender）**：
  - 毫米标尺画布，自由拖拽条形码（Code 128）、二维码（QR）、文本框，支持保存为 JSON 模板。
- 🌐 **中西双语（中文 / Español）一键切换**：
  - 方便国内运营团队与墨西哥等海外仓外籍员工无障碍协同。
- 🖨️ **1:1 毫米级绝对尺寸所见即所得**：
  - 矢量高精点阵渲染，锁死纸张规格与 0 边距，条码绝不失真拉伸。

---

## 🚀 本地开发与运行

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务 (http://localhost:3000)
npm run dev

# 3. 生产打包
npm run build
```

---

## 📦 部署到 GitHub Pages

项目已内置 `.github/workflows/deploy.yml` 自动化工作流。只需将代码推送到 GitHub 仓库的 `main` 分支，并在 GitHub 仓库的 **Settings -> Pages** 中将 **Source** 选为 **GitHub Actions**，系统将自动构建并上线免费访问！
